# Ikenna Ezeani — Portfolio (TanStack Start)

A full-stack React portfolio built on [TanStack Start](https://tanstack.com/start) — SSR + file-based routing via TanStack Router, bundled with Vite. Ported from the original single-file design; all animations preserved.

## Run

```bash
cd tanstack-app
npm install
npm run dev        # http://localhost:3000
```

`npm run build` for a production bundle, `npm run start` to serve it.

## Structure

```
src/
  router.tsx          # router factory
  routeTree.gen.ts    # AUTO-GENERATED by the router plugin on first run
  styles.css          # design tokens, keyframes, hover states
  routes/
    __root.tsx        # <html> shell, <head> meta + Google Fonts
    index.tsx         # the portfolio page + all animation logic (useEffect)
public/
  avatar.jpeg         # hero / nav / contact avatar
```

## Notes

- `routeTree.gen.ts` is a checked-in stub so TypeScript resolves before the first
  run; the TanStack Router Vite plugin overwrites it automatically. If you add
  routes and types look stale, delete it and re-run `npm run dev`.
- Motion (custom cursor, magnetic buttons, card tilt/glow, masked headings,
  scroll progress, parallax, avatar float + cursor parallax, count-ups, the
  company→role flip) lives in the `useEffect` in `src/routes/index.tsx` and is
  fully gated behind `prefers-reduced-motion` and `pointer: fine`.
- Dependency versions in `package.json` are recent-stable ranges; run
  `npm install` to lock the current patch releases.
- Content (projects, jobs, skills, posts) is plain data arrays at the top of
  `index.tsx` — edit there. Blog titles are placeholders.
